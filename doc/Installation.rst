.. _INSTALL/pip:

Using PIP to Install from PyPI
******************************

The following instructions use PIP (Package Installer for Python) as a package manager and PyPI (Python Package Index)
as a source of Python packages.

.. tab-set::

   .. tab-item:: Linux/macOS
      :sync: Linux

      .. code-block:: bash

         # Install pyTooling.Sphinx
         pip3 install pyTooling.Sphinx

         # Update pyTooling.Sphinx
         pip3 install -U pyTooling.Sphinx

         # Uninstall pyTooling.Sphinx
         pip3 uninstall pyTooling.Sphinx

   .. tab-item:: Windows
      :sync: Windows

      .. code-block:: powershell

         # Install pyTooling.Sphinx
         pip install pyTooling.Sphinx

         # Update pyTooling.Sphinx
         pip install -U pyTooling.Sphinx

         # Uninstall pyTooling.Sphinx
         pip uninstall pyTooling.Sphinx
